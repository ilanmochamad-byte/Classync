Kebijakan Privasi Classync App

Informasi yang Kami Kumpulkan

Kami mengumpulkan informasi berikut untuk menjalankan fungsi Aplikasi:

  1. Informasi Identifikasi Pribadi:

    • NIP/NIK dan Kata Sandi: Digunakan secara eksklusif untuk proses login dan autentikasi Anda. Kata sandi disimpan dengan aman (misalnya, di-hash).

    • Nama Lengkap: Digunakan untuk identifikasi di seluruh Aplikasi (misalnya, pada jadwal, profil, galeri).

    • Foto Profil: Digunakan untuk personalisasi tampilan profil Anda dan identifikasi visual di fitur galeri (jika Anda mengunggahnya).

    • Data Profil Lainnya (Opsional): Kontak, tempat/tanggal lahir, riwayat pendidikan, tugas tambahan yang mungkin Anda masukkan saat mengedit profil.

  2. Informasi Penggunaan & Aktivitas:

    • Data Absensi: Catatan waktu, tipe absensi (mengajar, piket, ekskul), status kehadiran siswa (jika relevan), dan ID jadwal terkait.

    • Foto Bukti Absensi: Gambar yang Anda ambil melalui Aplikasi sebagai bukti kehadiran saat melakukan absensi.

    • Data Interaksi: Catatan like atau dislike yang Anda berikan pada postingan di galeri aktivitas.

    • Data Penilaian Siswa: Nilai formatif dan sumatif beserta keterangannya yang Anda input untuk siswa.

  3. Informasi Perangkat (Otomatis):

    • Untuk fungsionalitas notifikasi lokal, Aplikasi mungkin berinteraksi dengan API perangkat untuk menjadwalkan pengingat, namun kami tidak secara aktif mengumpulkan ID unik perangkat untuk pelacakan.

Bagaimana Kami Menggunakan Informasi Anda

Informasi yang kami kumpulkan digunakan secara ketat untuk tujuan operasional internal SMK Terpadu Al Hasan Ciamis, termasuk:

  • Autentikasi: Memverifikasi identitas Anda saat login.

  • Pencatatan Kehadiran: Mencatat dan memverifikasi kehadiran Anda untuk kegiatan mengajar, piket, dan ekstrakurikuler.

  • Perhitungan Honorarium: Menggunakan data kehadiran sebagai dasar perhitungan honorarium bulanan Anda.

  • Pengelolaan Jadwal: Menampilkan jadwal Anda dan mengirimkan pengingat melalui notifikasi lokal.

  • Pengelolaan Akademik: Memfasilitasi input dan penyimpanan nilai siswa, serta menampilkan riwayat akademik siswa kepada guru yang berwenang.

  • Komunikasi Internal: Menampilkan aktivitas (termasuk foto bukti) dan interaksi (like/dislike) antar guru dalam fitur galeri.

  • Pengelolaan Profil: Memungkinkan Anda melihat dan memperbarui data profil Anda.

  • Penyediaan Sumber Daya: Memberikan akses ke sumber daya eksternal (seperti Perangkat Ajar Kemdikbud) melalui WebView.

  • Pemeliharaan & Peningkatan: Memahami bagaimana Aplikasi digunakan untuk tujuan perbaikan bug dan peningkatan fitur internal.

Pembagian Informasi

Karena Aplikasi ini bersifat internal, informasi Anda tidak akan dibagikan, dijual, atau disewakan kepada pihak ketiga eksternal untuk tujuan pemasaran atau lainnya. Pembagian informasi sangat terbatas pada:

  • Administrasi Sekolah: Data kehadiran, penilaian, dan profil dapat diakses oleh bagian administrasi SMK Terpadu Al Hasan Ciamis untuk keperluan penggajian, pelaporan, dan evaluasi kinerja.

  • Antar Pengguna Internal: Nama, foto profil, foto bukti absensi, dan interaksi like/dislike Anda akan terlihat oleh pengguna lain (guru) dalam fitur galeri aktivitas. Data profil lainnya tidak dibagikan antar guru melalui Aplikasi.

  • Penyedia Layanan Teknis: Kami mungkin menggunakan penyedia layanan hosting untuk server backend API kami. Penyedia ini terikat kontrak untuk menjaga kerahasiaan data Anda.

Keamanan Data

Kami menerapkan langkah-langkah keamanan teknis dan organisasi yang wajar untuk melindungi informasi pribadi Anda dari akses, pengungkapan, perubahan, atau penghancuran yang tidak sah. Ini termasuk penggunaan koneksi aman (HTTPS) untuk komunikasi dengan server dan praktik penyimpanan data yang aman.

Penyimpanan Data

Data pribadi dan data aktivitas Anda akan disimpan selama Anda masih aktif sebagai guru/staf di SMK Terpadu Al Hasan Ciamis, atau sesuai dengan kebijakan retensi data yang berlaku di lembaga kami.

Hak Anda

Anda memiliki hak untuk mengakses dan memperbarui informasi profil Anda melalui Aplikasi (fitur Edit Profil). Untuk permintaan akses data lain, koreksi data yang tidak dapat diubah melalui aplikasi, atau penghapusan data (sesuai kebijakan sekolah), silakan hubungi administrasi SMK Terpadu Al Hasan Ciamis.

Privasi Anak

Aplikasi ini ditujukan untuk digunakan oleh guru dan staf (orang dewasa). Meskipun Aplikasi ini mungkin menampilkan data siswa (seperti nama, kelas, nilai, absensi), data tersebut diakses oleh guru yang berwenang sesuai dengan kebijakan perlindungan data siswa yang berlaku di SMK Terpadu Al Hasan Ciamis. Kami tidak secara sengaja mengumpulkan data pribadi langsung dari siswa melalui Aplikasi ini.

Perubahan Kebijakan Privasi

Kami dapat memperbarui Kebijakan Privasi ini dari waktu ke waktu. Jika ada perubahan signifikan, kami akan memberitahu Anda melalui pengumuman internal atau pembaruan di Aplikasi. Kelanjutan penggunaan Aplikasi setelah perubahan menandakan persetujuan Anda terhadap kebijakan yang baru.
